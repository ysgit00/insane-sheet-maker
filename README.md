# SF Sheet Maker

사이코로 픽션(Saikoro Fiction) TRPG 캐릭터 시트 메이커입니다. 현재는 **인세인(INSANE)** 을 지원합니다.

캐릭터 시트를 브라우저에서 작성하고, A4 PDF로 저장하는 비공식 팬메이드 툴입니다.

**사용하기 → https://ysgit00.github.io/sf-sheet-maker/**

## 기능

- 입력하는 즉시 시트 위에 미리보기
- 특기 / 호기심 / 공포심, 생명력·이성치, 인물란, 아이템, 메모, 초상화 표시
- 어빌리티: 월드세팅별 목록에서 고르면 타입·지정특기·효과가 자동으로 입력됨 (직접 입력도 가능)
- **인쇄 / PDF 저장**: 브라우저 인쇄 창에서 "PDF로 저장"을 선택 (A4 가로)
- 입력 내용은 브라우저에 자동 저장되며, **시트 저장 / 시트 열기**로 JSON 파일로 보관할 수 있음

로컬에서 쓰려면 레포를 내려받아 `index.html`을 브라우저로 열면 됩니다. 별도 설치나 빌드는 필요 없습니다.

## 어빌리티 데이터

룰북 저작권을 지키기 위해 어빌리티 데이터는 **포함되어 있지 않습니다.**
갖고 있는 룰북을 보고 월드세팅별 JSON 파일을 만든 뒤, 화면의 **어빌리티 데이터 불러오기**(데이터가 있으면 월드세팅 오른쪽 **추가**)로 올려 사용하세요.
여러 파일을 한 번에 고를 수 있고, 불러온 데이터는 브라우저에만 저장됩니다.
양식은 데이터가 없을 때 보이는 **템플릿** 버튼으로 받을 수 있습니다.

```json
{
  "world": "1권",
  "rename": { "카메라": "항해술" },
  "abilities": {
    "어빌리티 이름": { "type": "공격", "skill": "폭력", "effect": "효과 텍스트" }
  }
}
```

| 필드 | 값 |
|---|---|
| `type` | `공격` / `서포트` / `장비` |
| `rename` | (선택) 월드세팅에서 바뀌는 특기명·분야명. 체크하면 폼과 시트의 이름이 바뀜 |
| `skill` | 특기명 / 분야명(그 분야 아무거나) / `임의`(전체) / `없음`. 쉼표로 여러 개 지정 가능 (예: `폭력, 의학`) |

여러 월드세팅을 한 파일에 담으려면 위 객체들을 배열(`[{...}, {...}]`)로 묶으면 됩니다.
로컬 보관용 `data/` 폴더는 `.gitignore`에 등록되어 있습니다.

## 저작권 및 라이선스

- 이 툴은 비공식 팬메이드이며, 원작 권리자와 관계가 없습니다.
- 『인세인』의 저작권은 카와시마 토이치로(河嶋陶一朗)와 모험기획국(冒険企画局)에 있습니다. 일본어판은 신키겐샤(新紀元社), 한국어판은 TRPG Club에서 출간했습니다.
- `sheet.jpg`는 [TRPG Club 공식 배포 캐릭터 시트](https://www.trpgclub.com/?p=375)이며, 저작권은 원작 권리자에게 있습니다.
- 룰북 본문(어빌리티 효과 등)은 이 레포에 포함되어 있지 않습니다.
- 권리자가 요청하면 즉시 내용을 수정하거나 삭제하겠습니다. 문의는 [Issues](https://github.com/ysgit00/sf-sheet-maker/issues)로 해 주세요.
